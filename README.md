### 🌱 About me

I'm a senior software engineer based in Nairobi, spending my days deep in backend architecture — APIs, databases, microservices, the unglamorous plumbing that keeps systems standing. I've rebuilt production systems under pressure, shaved 30% off release cycles, and generally like the kind of problems that make you stare at a whiteboard for an hour before writing a line of code.

Outside of the day job, I'm Irene of **Living Beyond Labels** — I run the **Inspirene Revolution** (a philanthropic initiative) and **Kuza Crowns / Crown Psychology** (pageant coaching), and I wrote the *Inspired Revolution* journal. It's an unusual pairing — backend systems and pageant psychology — but both are really about the same thing: building something structurally sound, whether that's an API or a person's confidence.

Right now I'm in a curious, in-between chapter. A few things I'm actively chewing on:

- 🔍 **Open source** — figuring out how to go from "uses open source" to "contributes to open source" in a real, sustained way, not just a one-off PR.
- 🧭 **Technical Product Management** — weighing whether the next step is going deeper into engineering or moving toward the intersection of product and tech, where I'd get to shape *what* gets built, not just *how*.
- 🚀 **Founder life** — exploring what it would look like to build something of my own from the ground up, using the systems thinking I've built over years of enterprise engineering.
- 🤖 **The AI age** — thinking about where engineers, PMs, and founders actually add value when the tools themselves are getting smarter every quarter.

I don't have this all figured out yet, and that's kind of the point of this README — it's less "final answer" and more "here's what I'm building toward."
